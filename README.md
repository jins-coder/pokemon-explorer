# pokemon-explorer

A simple Pokémon explorer built with Next.js and PokéAPI.

## Features

- Search by name or number
- Filter by elemental type
- Sort by stats (HP, Attack, Speed)
- Detail page with base stats, abilities, and moves
- Normal / Shiny sprite toggle

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
